Tools / Software Required
1. Microsoft Power BI Desktop

Dataset Source:
Global Superstore Dataset (Kaggle)
https://www.kaggle.com/datasets/apoorvaappz/global-super-store-dataset
Theory
A Dashboard is a visual interface that presents important business metrics, trends, and
performance indicators in a consolidated view. Dashboards help executives and managers
monitor organizational performance and make informed decisions.
A Scorecard is a management tool used to compare actual performance against predefined
targets. Scorecards help organizations track progress toward strategic objectives using Key
Performance Indicators (KPIs).
Power BI provides a rich set of visualization tools, KPI cards, charts, slicers, filters, and
interactive features that allow users to build professional dashboards and scorecards.
